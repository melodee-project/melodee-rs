# Media Corpus

compilations, comedy/spoken-word, skits/intros, track-level Artists, malformed tags, corrupt/truncated
files, oversized artwork, Unicode/RTL metadata, duplicate and alternate recordings, CUE/NFO/M3U/SFV,
and partial-copy scenarios.

Never commit private commercial audio. Store fixture provenance and licensing beside each asset.
