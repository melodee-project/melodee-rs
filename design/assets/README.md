# Melodee Spectrum Carbon — production logo assets

Rebuilt as native vector artwork; nothing in this package is cropped from the concept sheet.

- SVG files are resolution independent.
- Primary PNG exports are 4096 px.
- Transparent logo lockups are included for dark and light backgrounds.
- Square and rounded app icons, a circular badge, social graphics, and a complete favicon set are included.
- The Melodee wordmark is converted to vector outlines from Inter Display Medium, so the SVGs have no font dependency.

Primary palette: #FF2DBD, #FF4F87, #FF6A00, #FFD600, #00E0C6, #4DA7FF, #B14DFF, #091117, #101820, #FFFFFF.
