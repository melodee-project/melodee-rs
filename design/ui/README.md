# Melodee Admin UI

The Rust rewrite's web application is an administration, curation, identity, policy, and operations
console. Dedicated native/OpenSubsonic/Jellyfin clients remain the primary listening experiences.

The UI candidate selected for implementation is Carbon Design System, subject to ADR-0109 acceptance.
Canonical mockups establish visual intent; the written design system and actual implemented components
are authoritative for behavior, accessibility, responsive design, and tokens.
