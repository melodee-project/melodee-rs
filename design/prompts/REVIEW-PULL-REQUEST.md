# Review a Melodee Rewrite Pull Request

Review against requirement IDs, scope boundaries, accepted ADRs, external compatibility, data/public
ID preservation, idempotency/fault behavior, performance evidence, FOSS dependency policy, security,
localization/accessibility, and tests. Flag tactical C# translation, framework leakage into the domain,
meaningful differences hidden by normalization, destructive behavior without audit/recovery, or claims
not backed by reproducible evidence.
