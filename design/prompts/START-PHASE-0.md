# Coding Agent Kickoff — Phase 0

Read `AGENTS.md`, `PRD.md`, `SPEC.md`, `IMPLEMENTATION.md`, all accepted ADRs, and
`design/agents/PHASE-0-WORK-PACKAGE.md`. Own and complete Phase 0 end to end. Treat
`design/agents/FIRST-10-ISSUES.md` as the phase's internal starting backlog: establish its
dependency order, complete every in-scope issue, and continue through the Phase 0 exit criteria
without asking the user to assign each issue separately.

Before coding:

1. Restate the requirement IDs and acceptance criteria.
2. Identify legacy evidence needed and where it will be captured.
3. Identify applicable ADRs and whether a proposed ADR blocks work.
4. State exact files expected to change.
5. Keep the implementation within Phase 0.

Finish by running the repository check, documenting evidence, updating traceability, and producing
the phase exit report. A passing first issue is a checkpoint, not completion. Do not begin feature
parity implementation simply because the scaffold compiles.
