Melodee's OpenSubsonic adapter implements the OpenSubsonic API for third-party clients, including
JSON, XML, and JSONP response envelopes. Supported extensions and intentionally unsupported
endpoints (documented `410`/`501` behavior) are part of the compatibility contract.

The supported endpoint matrix will be published from the captured compatibility evidence in
`/compatibility`, verified by differential tests — never assumed.
