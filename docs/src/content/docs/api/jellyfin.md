Melodee's Jellyfin adapter covers music-focused Jellyfin client workflows: server discovery,
authentication, item/library views, artists, genres, playlists, sessions, images, and audio
streaming. Non-music Jellyfin features are intentionally not implemented.

Supported clients and smoke workflows will be documented from captured compatibility evidence in
`/compatibility` as the adapter ships.
