Melodee provides a Jellyfin-compatible API surface covering music workflows: discovery, login,
library views, artists, genres, playlists, images, and audio playback. Non-music Jellyfin behavior
is intentionally out of scope.

:::caution[Planned documentation]
The supported Jellyfin client matrix and smoke workflows will be documented from the rewrite's
Jellyfin adapter and its captured compatibility contracts.
:::
