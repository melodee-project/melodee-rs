A Release is the curated unit of the Melodee catalog — the primary thing processing, review, and
policy act on. Compatibility APIs may expose Releases as "albums"; the catalog itself is
release-centric.

:::caution[Planned documentation]
Release management operations (editing metadata, artwork, traits, and reprocessing) will be
documented against the shipped Rust implementation.
:::
