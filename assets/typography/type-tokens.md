# Melodee typography tokens

Primary family: **IBM Plex Sans**. Code/technical values: **IBM Plex Mono**. Font files are deliberately not redistributed.

| Token | Size | Line height | Weight | Tracking | Usage |
|---|---:|---:|---:|---:|---|
| `code-01` | 12px | 16px | 400 | 0.32px | IDs, paths, codecs, checksums, technical metadata |
| `label-01` | 12px | 16px | 400 | 0.32px | Labels, captions, overlines |
| `helper-text-01` | 12px | 16px | 400 | 0.32px | Field help, validation guidance |
| `body-compact-01` | 14px | 18px | 400 | 0.16px | Dense rows and compact components |
| `body-01` | 14px | 20px | 400 | 0.16px | Default application body copy |
| `body-02` | 16px | 24px | 400 | 0px | Onboarding and expressive body copy |
| `heading-compact-01` | 14px | 18px | 600 | 0.16px | Table headers and compact component headings |
| `heading-compact-02` | 16px | 22px | 600 | 0px | Prominent compact headings |
| `heading-01` | 14px | 20px | 600 | 0.16px | Small section and component headings |
| `heading-02` | 16px | 24px | 600 | 0px | Section headings |
| `heading-03` | 20px | 28px | 400 | 0px | Page subsection headings |
| `heading-04` | 28px | 36px | 400 | 0px | Page title |

| `display-01` | clamp(3rem, 2rem + 4vw, 5rem) | 1.05 | 300 | -0.02em | Rare top-level expressive display |
| `wordmark` | clamp(2.5rem, 2rem + 2vw, 4.5rem) | 1 | 400 | -0.025em | Logo wordmark only |

## Rules

- Use sentence case in the application.
- Use productive type for task-focused views, forms, tables, and settings.
- Use expressive type only where the page opens up: welcome, empty state, onboarding, and large page headers.
- Never substitute the logo wordmark with bold or condensed type.
- Keep long-form copy left aligned and constrain line length to approximately 60–75 characters.
